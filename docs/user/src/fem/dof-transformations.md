# DOF transformations

Two cells sharing an edge or face usually list its vertices in different orders. On a higher-degree
element, or on a vector element with directional moments, the interior degrees of freedom attached
to that entity therefore sit in different orders or signs on the two cells. **DOF transformations**
map canonical sub-entity DOFs (defined by [Orientation bits](../elements/orientation-bits.md)) into
each cell's local reference frame so neighbouring cells agree on every shared trace.

`tetraloma-element` computes the generating **base transformations** when
[`Element::get`](../api/tetraloma_element/struct.Element.html) builds an element, classifies them
with [`TransformationKind`](../api/tetraloma_element/enum.TransformationKind.html), and exposes
each generator through `Element::base_transformation`.

## Base transformations

Each sub-entity's symmetry group is generated by one or two elementary maps named by
[`Generator`](../api/tetraloma_element/enum.Generator.html):

| Sub-entity | Generator | Coordinate map $\Phi_G(\xi)$ | Order |
| --- | --- | --- | --- |
| Interval (edge) | `Reversal` | $\xi \mapsto 1 - \xi$ | $2$ |
| Triangle (face) | `Rotation` | $(s, t) \mapsto (t, 1 - s - t)$ | $3$ |
| Triangle (face) | `Reflection` | $(s, t) \mapsto (t, s)$ | $2$ |
| Quadrilateral (face) | `Rotation` | $(s, t) \mapsto (t, 1 - s)$ | $4$ |
| Quadrilateral (face) | `Reflection` | $(s, t) \mapsto (t, s)$ | $2$ |

For every lower-dimensional sub-entity type on the cell and each generator that applies to it,
`tetraloma-element` computes the $n \times n$ matrix $M$ numerically—where $n$ is the number of
interior DOFs on that sub-entity—by evaluating the reoriented sub-entity DOF functionals on the
element's basis. Because every sub-entity of the same type uses the same affine parametrisation
rule and DOF layout, the base transformation depends only on the sub-entity type, so one table
serves every edge or face of that type on the cell.

`Element::base_transformation(entity, generator)` returns `None` if the cell has no
lower-dimensional sub-entities of type `entity`, if the element places no interior DOFs on them
(such as degree $0$ or $1$ Lagrange or `Variant::Legendre`), or if `generator` does not apply to
`entity`. Otherwise it returns a
[`BaseTransformation`](../api/tetraloma_element/enum.BaseTransformation.html) mapping canonical
sub-entity DOFs $x$ to cell-local DOFs $y = M x$:

- `BaseTransformation::SignedPermutation { perm, negate }`: $y_i = -x_{\text{perm}[i]}$ if
  `negate[i]`, else $x_{\text{perm}[i]}$.
- `BaseTransformation::Dense { n, matrix }`: row-major $n \times n$ product
  $y_i = \sum_{j=0}^{n-1} M_{ij}\, x_j$.

```rust
use tetraloma::{CellType, NodeFamily};
use tetraloma_element::{
    BaseTransformation, Element, ElementKey, Family, Generator, Variant,
};

let el = Element::get(ElementKey {
    family: Family::Lagrange,
    cell: CellType::Tetrahedron,
    degree: 4,
    variant: Variant::Nodal(NodeFamily::Gll),
})?;
assert_eq!(
    el.base_transformation(CellType::Interval, Generator::Reversal),
    Some(&BaseTransformation::SignedPermutation {
        perm: vec![2, 1, 0],
        negate: vec![false, false, false],
    })
);
assert_eq!(
    el.base_transformation(CellType::Triangle, Generator::Rotation),
    Some(&BaseTransformation::SignedPermutation {
        perm: vec![2, 0, 1],
        negate: vec![false, false, false],
    })
);
assert_eq!(
    el.base_transformation(CellType::Triangle, Generator::Reflection),
    Some(&BaseTransformation::SignedPermutation {
        perm: vec![0, 2, 1],
        negate: vec![false, false, false],
    })
);
assert!(el.base_transformation(CellType::Quadrilateral, Generator::Rotation).is_none());
# Ok::<(), tetraloma_element::ElementError>(())
```

## Classification

`Element::transformation_kind()` summarises the strongest transformation needed across all
sub-entities as a [`TransformationKind`](../api/tetraloma_element/enum.TransformationKind.html):

- **`Identity`**: every base transformation is trivial, or the element has no DOFs on shared
  sub-entities. This holds for all intervals, all `Variant::Legendre` elements, and all nodal
  Lagrange elements with $p \le 2$.
- **`SignedPermutation`**: every base transformation is a signed permutation and at least one is
  non-trivial. Nodal Lagrange elements on cells of dimension $2$ and $3$ for $p \ge 3$ fall here
  (permutations without negation); tensor-product $H(\mathrm{curl})$ and $H(\mathrm{div})$ elements
  on quadrilaterals and hexahedra will also fall here once supported (with sign flips from odd
  Legendre moments).
- **`Dense`**: at least one base transformation is a dense block, as on triangular faces of
  higher-degree tetrahedral $H(\mathrm{curl})$ and $H(\mathrm{div})$ elements. `Family::N1curl`
  and `Family::RaviartThomas` currently return `ElementError::Unsupported` from `Element::get`, so
  no currently supported element produces `Dense`.

Let $M_c$ be the block-diagonal matrix mapping canonical global DOFs to cell $c$'s local
coefficients ($u_{\text{local}} = M_c u_{\text{global}}$), so the transformed basis is
$\phi_c = T_c \phi_{\text{ref}}$ with $T_c = M_c^{\mathsf T}$. Evaluation applies $M_c$ to
coefficients (equivalently $T_c$ to the basis), transposed assembly applies $M_c^{\mathsf T}$
($= T_c$), and interpolation recovers canonical DOFs with $M_c^{-1}$ ($= T_c^{-\mathsf T}$).
Because every signed permutation is orthogonal ($M_c^{-1} = M_c^{\mathsf T}$), interpolation
applies the transpose (inverse) signed permutation rather than a matrix solve.

```rust
use tetraloma::{CellType, NodeFamily};
use tetraloma_element::{Element, ElementKey, Family, TransformationKind, Variant};

let gll = Variant::Nodal(NodeFamily::Gll);
let kind = |cell, degree, variant| {
    Element::get(ElementKey { family: Family::Lagrange, cell, degree, variant })
        .map(|el| el.transformation_kind())
};
assert_eq!(kind(CellType::Hexahedron, 2, gll)?, TransformationKind::Identity);
assert_eq!(kind(CellType::Hexahedron, 3, gll)?, TransformationKind::SignedPermutation);
assert_eq!(kind(CellType::Interval, 6, gll)?, TransformationKind::Identity);
assert_eq!(kind(CellType::Hexahedron, 6, Variant::Legendre)?, TransformationKind::Identity);
# Ok::<(), tetraloma_element::ElementError>(())
```

## Neighbouring cells

To map canonical global DOFs to a cell's local reference coefficients, decode the cell's 32-bit
word from [`orientation_bits`](../api/tetraloma_refcell/fn.orientation_bits.html)
([Orientation bits](../elements/orientation-bits.md)) and transform each sub-entity's interior
slice `entity_dofs(d, e)`:

1. **Edges** ($d = 1$, for 2D and 3D cells): if bit $e$ is set, apply `Generator::Reversal` for
   `CellType::Interval` once to `entity_dofs(1, e)`.
2. **Faces** ($d = 2$, for 3D cells with $E$ edges): read the 3-bit field at shift $E + 3f$—low two
   bits `rot`, bit $2$ `refl`—and apply reflection once if `refl == 1`, then rotation `rot` times,
   forming $u_{\text{local}} = M_R^{\text{rot}} M_S^{\text{refl}} u_{\text{global}}$ on
   `entity_dofs(2, f)`.

Because orientation bits come from vertex origin ids, every MPI rank agrees on the transformation.
The example below verifies continuity across a reversed edge shared by two cubic triangles:

```rust
use tetraloma::{CellType, NodeFamily};
use tetraloma_element::{
    BaseTransformation, Element, ElementKey, Family, Generator, Variant,
};
use tetraloma_refcell::orientation_bits;

let el = Element::get(ElementKey {
    family: Family::Lagrange,
    cell: CellType::Triangle,
    degree: 3,
    variant: Variant::Nodal(NodeFamily::Gll),
})?;
// Edge 0 is canonical (0 -> 1) on A and reversed (1 -> 0) on B.
assert_eq!(orientation_bits(CellType::Triangle, &[0, 1, 2]) & 1, 0);
assert_eq!(orientation_bits(CellType::Triangle, &[1, 0, 3]) & 1, 1);

let (mut ca, mut cb) = (vec![0.0; el.dim()], vec![0.0; el.dim()]);
(ca[0], ca[1], cb[0], cb[1]) = (1.5, -0.5, -0.5, 1.5);
let edge_global = [2.0, -3.0];
let Some(BaseTransformation::SignedPermutation { perm, negate }) =
    el.base_transformation(CellType::Interval, Generator::Reversal)
else {
    unreachable!();
};
for (i, &dof) in el.entity_dofs(1, 0).iter().enumerate() {
    ca[dof] = edge_global[i];
    let v = edge_global[perm[i] as usize];
    cb[dof] = if negate[i] { -v } else { v };
}

for s in [0.15, 0.42, 0.78] {
    let (ta, tb) = (el.tabulate(&[s, 0.0], 0)?, el.tabulate(&[1.0 - s, 0.0], 0)?);
    let va: f64 = ca.iter().zip(&ta.values).map(|(c, b)| c * b).sum();
    let vb: f64 = cb.iter().zip(&tb.values).map(|(c, b)| c * b).sum();
    assert!((va - vb).abs() < 1e-13);
}
# Ok::<(), tetraloma_element::ElementError>(())
```
