# M12: N1curl and RT elements

Design: docs/design.md section 26; also 14, 16, 18, 20 (A.5, A.6, A.10, A.11), 22, 23 and 25 for the documentation, the tolerances, the crate graph, the oracles, the conventions, the protected paths and the glossary; ADR-0071, ADR-0077 and ADR-0080 (#143, PR #145)
Depends on: M11
Milestone issue: created with the task issues, after this plan is merged

## Scope

M12 delivers first-kind Nédélec (`Family::N1curl`) and Raviart–Thomas (`Family::RaviartThomas`) elements of section 26, on the host and in `f64`, with `Variant::Legendre` (their only variant):

- **Simplices (`Triangle`, `Tetrahedron`, degrees 1–15):** `N1curl_p` (`MapType::CovariantPiola`) and `RT_p` (`MapType::ContravariantPiola`), with `reference_value_size() == tdim`, `embedded_superdegree() == p`, `discontinuous_only() == false`, sub-entity Legendre moment DOFs, dense Ciarlet construction over `tetraloma-refcell::polyset` via `DenseLu`, and numerical base DOF transformations (signed permutations on edges and tetrahedral `RT_1` faces; dense blocks on tetrahedral faces for `p ≥ 2`).
- **Tensor cells (`Quadrilateral`, `Hexahedron`, degrees 1–20):** `RTCE_p` / `NCE_p` (`Family::N1curl`) and `RTCF_p` / `NCF_p` (`Family::RaviartThomas`), assembled from 1D factors (`Factor1d::MomentH1` and `Factor1d::LegendreL2`) with `TensorFactors::negate` (ADR-0080), fast tensor tabulation, lazy `coefficients()` and `interpolation_matrix()`, and signed-permutation base transformations.
- **Oracles:** committed Symfem `2025.12.0` sub-entity DOF-count fixture (`tetraloma-element/tests/fixtures/hcurl_hdiv_dofs_symfem.json`, written and checked by `scripts/fixtures/element/generate.py`), and direct in-process `conformance/` span rank tests against `ndelement` at the pinned commit `f8cbffe` (`conformance/tests/hcurl_hdiv.rs`; ADR-0080).
- **User documentation:** updated rustdoc and `# Example` doctests across `tetraloma-element`, updated prose and running doctests in `docs/user/src/fem/elements.md` and `docs/user/src/fem/dof-transformations.md`, and a `Piola map` entry in `docs/user/src/glossary.md` (section 25).

Left out (roadmap "Out of scope"):

- Second-kind families (N2curl, BDM, BDMCE, BDMCF); prisms and pyramids; point-evaluation DOFs (`Variant::Nodal(_)` stays `ElementError::Unsupported` for `N1curl` and `RaviartThomas`).
- Device kernels, quadrature extensions (`sub_entity_points_to_cell` in M13), and function spaces / evaluation / interpolation (M14–M17).

M12 adds and changes no kernel. So there is no vector-size invariance test, no task has a remote run, and CUDA first sees M12's changes at the gate.

### Where the code differs from the design today

Read from the code on the main branch at `2ffa13f` (and ADR-0080 in pull request #145).

1. **Key validation and element construction:** `layout::validate_key` and `Element::build` reject `Family::N1curl` and `Family::RaviartThomas` with `ElementError::Unsupported`. Two existing unit tests assert that `(N1curl, Triangle, 1, Legendre)` is rejected: `layout::tests::validate_key_accepts_full_lagrange_table_and_rejects_boundaries` and `lib::tests::error_display_source_and_from_refcell`. (`accept::unsupported_keys_return_unsupported` tests only keys genuinely outside section 26's table.) T6 updates those two unit tests.
2. **`Factor1d::MomentH1`:** declared in `tetraloma-element/src/tensor.rs`, with rustdoc saying `"up to degree p − 2"` (ADR-0077 explicitly assigns M12 the rewording to `d − 2`). `TensorFactors::tabulate_1d` calls `unimplemented!()` on `Factor1d::MomentH1`, and `tensor::tests::tabulate_1d_panics_on_moment_h1` asserts that panic. T4 implements `MomentH1` (`d = 1..=20`) and replaces that test.
3. **`TensorFactors::negate`:** `TensorFactors` currently has only `factors` and `lexicographic`. ADR-0080 adds `pub negate: Vec<bool>` for the per-component sign forced by consistent facet-normal handedness on `RTCF` (component 0) and `NCF` (component 1). T0 adds the field (setting `vec![false]` on Lagrange elements).
4. **Vector Ciarlet solver and tabulation:** `ciarlet::solve_ciarlet_coefficients` and `ciarlet::tabulate_from_coefficients` handle `reference_value_size == 1` only. ADR-0080 fixes the vector layouts to `[dim][component][polyset]` for `coefficients()` and `[dim][point][component]` for `interpolation_matrix()`. T2 adds the vector engine alongside the scalar path.
5. **Base transformations:** `transform::build_lagrange_transformations` handles scalar nodal Lagrange only; `BaseTransformation::Dense` and `TransformationKind::Dense` are declared but never constructed. T5 adds vector base transformations.
6. **Symfem pin:** `symfem` `v2025.12.0` (`c37ffd6951a7fddd99353335fd5a511efdcf18fc`) is recorded in `tetraloma-element/tests/fixtures/sources.json`, and `symfem==2025.12.0` is available on PyPI, but it is not yet pinned in `scripts/check-local-tools.sh`, `docs/dev-environment.md` or `scripts/fixtures/element/generate.py`. T1 adds it (Decision 4).
7. **`conformance/` dependencies and dev optimisation:** `conformance/Cargo.toml` does not yet depend on `tetraloma-element` or set `[profile.dev.package.*] opt-level = 3` (needed so `ndelement`'s dense `p = 8` hexahedron construction in A2 runs in seconds in debug builds). T0 adds both (ADR-0080).
8. **User documentation:** rustdoc on `Family`, `TransformationKind`, `BaseTransformation` and `Factor1d`, plus `docs/user/src/fem/elements.md` and `docs/user/src/fem/dof-transformations.md`, currently state that `N1curl`, `RaviartThomas`, `Dense` and `MomentH1` are not yet supported; `docs/user/src/glossary.md` lacks the `Piola map` entry of section 25. T4 and T6 update them without changing the fixed book outline in `scripts/doc_audit.py`.

Carried over from M11's gate record (`docs/reviews/M11.md`) and ADR-0077:

- **ADR-0077:** reword `Factor1d::MomentH1` rustdoc from `p − 2` to `d − 2` (T4).
- **M11 G8 (Decision 24):** degrees above `p = 10` (`p = 11–15` on triangles and tetrahedra; `p = 11–20` on quadrilaterals and hexahedra) are offered by section 26's table. T6 adds fast sampled high-degree interpolation/reproduction checks (`p = 12, 15` on simplices; `p = 12, 16, 20` on tensor cells, keeping hexahedron dense tables lazy) and documents the validated ranges in `Element::get` rustdoc and `fem/elements.md`.
- **M11 G12 (still for M13):** `transform::sub_entity_points_to_cell` stays private in `tetraloma-element` until M13 adds `tetraloma_refcell::sub_entity_points_to_cell`.

How the rows are read:

- **A1:** checks `el.entity_dofs(d, e).len()` for every `(d, e)` against the committed Symfem `2025.12.0` fixture (`hcurl_hdiv_dofs_symfem.json`, DefElement sub-entity numbering).
- **A2:** `ndelement` at `f8cbffe` implements both `nedelec` and `raviart_thomas` on all four cells (`Triangle`, `Quadrilateral`, `Tetrahedron`, `Hexahedron`), so Basix is not needed as a fallback. For every element, degree `p = 1..=8`, and sub-entity `(d, e)` with non-empty closure (`k = entity_closure_dofs(d, e).len()`), the test evaluates both bases at deterministic pseudo-random interior reference points (`100` points for `d < tdim`; `max(100, ⌈dim / tdim⌉ + 20)` points for `d = tdim`), forming `(m · tdim) × k` matrices `U` (tetraloma) and `V` (ndelement), and verifies by column-pivoted Householder QR that `rank(U) == k`, `rank(V) == k`, and every column of `V` has relative projection residual `‖(I − Q_U Q_Uᵀ) v_j‖₂ / ‖v_j‖₂ ≤ 10^−10` (and symmetrically `U` onto `Q_V`). For `d = tdim` on `Hexahedron` `p = 5..=8`, `U` and `V` are compared via `Q_U` on the `max(100, ⌈dim / tdim⌉ + 20)` points in `opt-level = 3` (total runtime a few seconds).
- **A3:** checks `M · B = I_dim` to `10^−12` with `M` in `[dim][point][component]` order (ADR-0080) and `B = el.tabulate(el.interpolation_points(), 0)` in `[point][basis][component]` order, skipping exact zeros of `M` so `Hexahedron` `p = 10` (`dim = 3630`, `m = 1720`) runs quickly.
- **A4:** constructs an independent `L²`-orthonormal basis of each element's polynomial space (`P_{p−1}^d ⊕ {q ∈ P̃_p^d : q · x = 0}` / `P_{p−1}^d ⊕ x P̃_{p−1}` on simplices via Gram–Schmidt over `polyset` under `gauss_rule(cell, 2p)`, and tensor products of 1D orthonormal Legendre polynomials per component on quadrilaterals and hexahedra), interpolates every member `u_k` via `c_k = M u_k(interp_pts)`, evaluates `Σ_j c_{k,j} φ_j` at interior and boundary test points via `Element::tabulate`, and checks relative error `≤ 10^−11`.
- **A5:** checks that every non-`None` `base_transformation` on `Quadrilateral` and `Hexahedron` for `N1curl` and `RaviartThomas`, `p = 1..=10`, is `BaseTransformation::SignedPermutation`, that `transformation_kind() == TransformationKind::SignedPermutation`, and (mirroring M11 Decision 22) that the raw base-transformation matrix evaluated directly from `Element::tabulate` matches the classified signed permutation to `10^−12`.
- **A6:** takes every pair of cell types of the same dimension that can share a sub-entity carrying N1curl DOFs — 2D: `(Triangle, Triangle)`, `(Quadrilateral, Quadrilateral)`, `(Triangle, Quadrilateral)` sharing an edge (2 orientations); 3D: `(Tetrahedron, Tetrahedron)` sharing an edge (2) or triangular face (6), `(Hexahedron, Hexahedron)` sharing an edge (2) or quadrilateral face (8), `(Tetrahedron, Hexahedron)` sharing an edge (2) — assigns random canonical global DOF values, maps to cell-local coefficients via `apply_cell_dof_transformations` (`u_local = M_R^rot M_S^refl u_global`, ADR-0077; exercising both `SignedPermutation` and tetrahedral `Dense` blocks), and verifies that tangential components `û_A · t_A` and `û_B · t_B` along the canonical sub-entity tangent(s) agree to `10^−12` for `p = 1..=6`.
- **A7:** takes every pair of cell types sharing a facet carrying RT DOFs — 2D: `(Triangle, Triangle)`, `(Quadrilateral, Quadrilateral)`, `(Triangle, Quadrilateral)` sharing an edge (2 orientations); 3D: `(Tetrahedron, Tetrahedron)` sharing a triangular face (6 orientations), `(Hexahedron, Hexahedron)` sharing a quadrilateral face (8 orientations) — and verifies that normal components `û_A · n_A` and `û_B · n_B` (where `n_A`, `n_B` are the canonical oriented normals `(-t_y, t_x)` or `t_1 × t_2` from the shared facet's canonical vertex order, covariant under `ContravariantPiola` on positively oriented cells) agree to `10^−12` for `p = 1..=6`.
- **A8, A9, A10:** for every basis function of the source element (`Lagrange_p` `Nodal(Gll)` for A8, `N1curl_p` for A9, `RT_p` for A10), evaluates its gradient / curl or rot / divergence from `tabulate(..., 1)`, projects into the target element (`N1curl_p` / `RT_p` or `DG_{p−1}` `Legendre` / `DG_{p−1}` `Legendre`) via the target's `interpolation_matrix()`, and verifies that the `L²` residual over `gauss_rule(cell, 2p)` (an upper bound on the least-squares residual) is below `10^−12` relative to the source derivative's `L²` norm (skipping zero-derivative constant functions).
- **A11:** unit test in `src/tensor.rs` (the dense tensor construction stays private, section 26); checks that the 1D factor product (negated where `tf.negate[c]` is true; ADR-0080) reproduces the private dense construction's values (and first derivatives) to `10^−12` on `Quadrilateral` and `Hexahedron` for `N1curl` and `RaviartThomas`, `p = 1..=8`.

### T3: simplex N1curl and RT construction

Orthonormal vector polynomial spaces and moment functionals for `N1curl` and `RaviartThomas` on `Triangle` and `Tetrahedron` (`p = 1..=15`).

- `tetraloma-element/src/simplex.rs` (new; wired as `mod simplex;` in `lib.rs`):
  - Orthonormal space bases via `ciarlet::orthonormalise_vector_basis` under `gauss_rule(cell, 2p)`:
    - `N1curl_p`: `P_{p−1}^d ⊕ {q ∈ P̃_p^d : q · x = 0}` (projected from `x × P̃_{p−1}` in 3D and `(y, −x) P̃_{p−1}` in 2D onto the degree-`p` `polyset` slice).
    - `RT_p`: `P_{p−1}^d ⊕ x P̃_{p−1}` (projected onto the degree-`p` `polyset` slice).
  - Moment functionals in `[dim][point][component]` order:
    - `N1curl`: tangential moments against `polyset(Interval, p − 1)` along `v_1 − v_0` on edges (`gauss_rule(Interval, 2p − 1)`); tangential vector moments against `polyset(Triangle, p − 2)²` along `(v_1 − v_0, v_2 − v_0)` on triangular faces (`gauss_rule(Triangle, 2p − 2)`, `p ≥ 2`); interior moments against `polyset(Triangle, p − 2)²` (`p ≥ 2`) or `polyset(Tetrahedron, p − 3)³` (`p ≥ 3`).

  - `build_simplex_hcurl_hdiv(key, dim)` returning `CiarletData`.
- Unit tests: space orthonormality to `10^−13`, `M B = I` to `10^−12` for `p = 1..=10`, simplex de Rham inclusions for `p = 1..=8`, and a smoke test at `p = 15`.

### T4: `MomentH1` 1D factor and tensor-product RTCE, RTCF, NCE, NCF

### T5: vector base transformations

Numerical computation and classification of base DOF transformations for `N1curl` and `RaviartThomas` on all four cells.

- `tetraloma-element/src/transform.rs`:
  - `build_hcurl_hdiv_transformations(key, dim, entity_dofs, tabulate_values)` evaluating reoriented sub-entity moment functionals on the element's basis:
    - `N1curl` (`CovariantPiola`): on edges (`Interval`, `Reversal`), `l_i^{E,G}(φ_j) = ∫_0^1 (φ_j(F_E(Φ_G(s))) · (J_G t_E)) ψ_i(s) ds`; on faces (`Triangle` / `Quadrilateral`, `Rotation` & `Reflection`), `T_G = T J_G` applied to the face's tangential vector moments (triangle: `P_{p−2}²`; quadrilateral: tensor `Q_{p−1,p−2} × Q_{p−2,p−1}` matching T4's face DOF order).
    - `RaviartThomas` (`ContravariantPiola`): on facets (`Interval`, `Triangle`, `Quadrilateral`), `l_i^{E,G}(φ_j) = ∫_{K̂_E} (φ_j(F_E(Φ_G(ξ_E))) · ((det J_G) n_E)) ψ_i(ξ_E) dξ_E`.
  - Classified with `classify_matrix` and `classify_kind`: asserts `SignedPermutation` for edges and quadrilateral faces (at every supported degree); permits `Dense` on triangular faces of tetrahedra (`p ≥ 2`).
- Unit tests: dihedral/symmetric group relations (`R^k = I`, `S^2 = I`, `(RS)^2 = I` to `10^−12` for both `SignedPermutation` and `Dense` matrices), invariance across every edge/face of the same type on the cell, classification checks (`SignedPermutation` on Tri, Quad, Hex and Tet `p = 1`; `Dense` on Tet `p ≥ 2`), and an explicit physical-cell `CovariantPiola`/`ContravariantPiola` continuity test on rotated cell pairs.
